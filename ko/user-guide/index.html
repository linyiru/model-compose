핵심 개념

  • 컨트롤러(Controller): 워크플로우를 호스팅하는 HTTP 또는 MCP 서버
  • 컴포넌트(Component): 재사용 가능한 정의 (API 호출, 모델, 명령어)
  • 워크플로우(Workflow): 이름이 지정된 작업 순서
  • 작업(Job): 컴포넌트를 실행하는 단일 단계
  • 리스너(Listener): HTTP 콜백을 받거나 워크플로우를 트리거
  • 게이트웨이(Gateway): 로컬 서비스를 인터넷에 터널링
