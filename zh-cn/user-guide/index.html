关键概念

  • 控制器（Controller）：托管工作流的 HTTP 或 MCP 服务器
  • 组件（Component）：可重用的定义（API 调用、模型、命令）
  • 工作流（Workflow）：命名的作业序列
  • 作业（Job）：执行组件的单个步骤
  • 监听器（Listener）：接收 HTTP 回调或触发工作流
  • 网关（Gateway）：将本地服务隧道到互联网
